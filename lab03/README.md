### 1 (3) Составьте глоссарий из определений лекции. Проверка отчета будет включать проверку знания определений.
* Тип — атрибут объекта данных, задающий множество допустимых значений и методы для работы с ними.
* Статическая типизация - тип данных объекта, который определяется в момент трансляции программы.
* Динамическая типизация - это когда тип данных переменной определяется во время работы программы при её выполнении.
* Неявная типизация - тип данных переменной определяется во время работы программы при её выполнении
* Явное преобразование типа - это преобразование, которое указано в виде вызова функции или в виде операции.
* Неявное преобразование типа - преобразование, которое не присутствует в программе в виде конкретного указания, а транслятор сам подставляет требуемый метод преобразования.
* Сильная типизация - язык программирования не содержит (почти не содержит) правил неявного преобразования типа.
* Слабая типизация  - язык программирования содержит большое число правил неявного преобразования типа, допускает каламбуры типизации.

### 5 (2) Приведите разумные (логичные) примеры использования в С++ ключевых слов typedef, auto, decltype, static_cast. Записанные программы сохраните в папке с номером задания. В отчет запишите пояснения к программам

1. typedef

```typedef int I;
I age = 19;
```
typedef создаёт дополнительное имя для существующего типа. В данном случае I является другим именем для типа int.

2. auto

```auto b = 99.5;```
Ключевое слово auto позволяет компилятору автоматически определить тип переменной по её начальному значению. В данном случае переменная b имеет тип double.

3. decltype

```int n = 10;
decltype(n) dn = 20;
```
decltype позволяет получить тип указанного выражения. Так как n имеет тип int, переменная dn также имеет тип int.

4. static_cast

```double c = 7.8;
int f = static_cast<int>(c);
```
static_cast выполняет явное преобразование типа. В данном случае значение типа double преобразуется в int, поэтому значение 7.8 становится 7.

Результат работы программы:

```typedef: 19
auto: 99.5
decltype: 20
static_cast: 7
```

### 7 (2) Рассмотрите следующий фрагмент программы.
```int x = 7 , y = 4;
long double d = 0.25;
cout << (x / y) / d << endl ;
cout << (x / d) / y << endl ;
long a = 200000 , b = 200000;
long long c = 200000;
std :: cout << (a * b ) * c << std :: endl ;
std :: cout << a * (b * c) << std :: endl ;
```
Почему изменения порядка действий приводит к изменению
результата? Объясните работу этой программы, используя правила
неявного преобразования типов.

В первых двух выражениях порядок действий влияет на результат из-за целочисленного деления.

В выражении:

`(x / y) / d`
сначала выполняется 7 / 4. Так как оба операнда имеют тип int, выполняется целочисленное деление:
7 / 4 = 1
После этого 1 преобразуется в long double и выполняется:
1 / 0.25 = 4

Во втором выражении:

`(x / d) / y`
сначала x преобразуется из int в long double, так как второй операнд d имеет тип long double:
7 / 0.25 = 28
Затем:
28 / 4 = 7

Таким образом, изменение порядка действий меняет результат из-за того, что в первом случае сначала выполняется целочисленное деление и теряется дробная часть.

Во второй части программы используются типы long и long long.

В выражении:

`(a * b) * c`
сначала вычисляется a * b. На системе, где long имеет размер 32 бита, промежуточный результат 200000 * 200000 = 40000000000 не помещается в long, поэтому происходит переполнение.

В выражении:

`a * (b * c)`
сначала вычисляется b * c. Так как c имеет тип long long, значение b неявно преобразуется в long long, и промежуточный результат сохраняется в long long. Поэтому переполнения long на этом этапе не происходит.

Таким образом, изменение порядка действий может изменить результат вычисления из-за типа промежуточных результатов и выполняемых неявных преобразований.

### 8 (2) Для каких значений целочисленных переменных x,y,z результатом выражения ```(x==y)+(x==z)==true``` будет истина? Перечислите все случаи. Объясните работу этой программы, используя правила неявного преобразования типов.

Выражение: `(x == y) + (x == z) == true` будет истинным, если только одно из сравнений `x == y` и `x == z` истинно.

В C++ значение bool при арифметической операции неявно преобразуется в int:

* true > 1;
* false > 0.

Поэтому сумма двух сравнений должна быть равна 1.

Все случаи:

1. x = y и x ? z;
2. x = z и x ? y.

Например, при x = 5, y = 5, z = 3 получаем 1 + 0 = 1, поэтому выражение истинно.

При x = y = z оба сравнения дают true, поэтому 1 + 1 = 2, и выражение ложно.

### 9 (2) Проверьте работу логического выражения x == y == z в языках Python, Java, C++ для целочисленных переменных x, y, z. Объясните результат для каждого из языков. Подсказка. Результат будет различным для каждого из языков. Для Python потребуется познакомиться с цепочечными сравнениями. Для С++ подумать про неявные преобразования типов.

1. Python:
В Python это цепочка сравнений: (x == y) and (y == z)

Выражение истинно, если x = y = z.

2. Java:
Выражение x == y == z не компилируется. Сначала x == y даёт значение типа boolean, после чего это значение пытаются сравнить с z, имеющим тип int. Java не допускает такое сравнение.

3. C++:
В C++ выражение вычисляется слева направо: (x == y) == z

Результат x == y имеет тип bool. При сравнении bool с int значение bool неявно преобразуется в int: true > 1, false > 0.

Например, при x = 5, y = 5, z = 1:

x == y > true > 1
1 == z > 1 == 1 > true

Таким образом, одинаковая запись x == y == z имеет разный смысл в Python, Java и C++.
