### Задание 5
```
print (*map (sum, zip (
*[map (int, input (). split ()) for i in (1,2,3)]
)))
```
Ключевые слова: `for`, `in`
Идентификаторы: `print`, `map`, `sum`, `zip`, `int`, `input`, `split`, `i`
Литералы: `1` `2` `3` 
Операторы: `.` `*` `()` `[]` 

Вызывает функции:
* `input()` - без параметров; функция возвращает одну введеную пользователем строку 
* `split()` - метод без параметров; разбивает введённую строку на части по пробелам
* `map(int, input().split())` - параметры: функция int и список строк, возвращает каждый элемент строки в целое число
* `zip(*[...])` - параметры: три итератора распакованные из списка через *, объединяет элементы всех строк вместе с одинаковыми позициями 
* `map(sum,zip(...))` - параметры: функция sum и итератор zip, возвращает итератор сумм по столбцам 
* `print(*map(...))` - параметры: значения из итератора, распакованные из итератора через *

Программа читает три строки, содержащие целые числа,разделённые пробелами, и выводит суммы чисел по столбцам.

* [map(int, input().split()) for i in (1, 2, 3)] — цикл выполняется трижды.
* input().split() — на каждой итерации читается одна строка и разбивается по пробелам в список строк.
* map(int, ...) — каждая строка преобразуется в целое число.
* zip(*[...]) — оператор * распаковывает список итераторов, передавая их как отдельные аргументы в zip. Функция zip группирует элементы с одинаковыми индексами в столбцы.
* map(sum, zip(...)) — к каждому столбцу, полученному от zip, применяется функция sum. В результате получается итератор сумм по столбцам.
* print(*map(...)) — оператор * распаковывает итератор сумм, и print выводит их через пробел.

В результате программа выводит суммы чисел по каждому столбцу.

### Задание 6 

В C++ комментарии можно записывать двумя способами:
* // — однострочный комментарий. Всё после // до конца строки игнорируется.
* /* ... */ — многострочный комментарий. Заканчивается */.

* Синтаксически неверные примеры:

1.  cout <<" Hello /* Это комментарий */ world ";

Ошибка: /* ... */ внутри строкового литерала — это не комментарий, а часть текста.

2. // /*
Это комментарий
*/

Ошибка: // комментирует только первую строку. Строки Это комментарий и */ становятся отдельными строками кода.

3. /* Я комментирую программы /* комментарий */ */

Ошибка: в C++ не нельзя использовать вложенность многострочных комментариев. Комментарий заканчивается на первом */. Последние  */ окажутся вне комментария и вызовут ошибку синтаксиса.

* Синтаксически верные примеры: 

1. // Я комментирую программы /* комментарий */

Вся строка является однострочным комментарием, поэтому /* комментарий */ внутри нее также является обычным текстом комментария.

2. /* Я комментирую свои программы
// Это комментарий до конца строки */

Сначала /* открывает многострочный комментарий. Строка с // находится внутри него не начинается отдельный комментарий. Закрывается последним */.

Таким образом, синтаксически верными являются 1, 4 и 5 примеры, а 2 и 3 являются ошибочными.

### Задание 7

В приложении А.5 приведены 4 формальных правила для инструкций циклов:

```
iteration-statement:
    while ( condition ) statement
    do statement while ( expression ) ;
    for ( init-statement conditionopt ; expressionopt ) statement
    for ( for-range-declaration : for-range-initializer ) statement
```

* Первый вид — цикл while, который соответствует строке правила:

while ( condition ) statement

Сначала записывается ключевое слово while, затем в круглых скобках указывается условие condition, после чего записывается инструкция statement, которая выполняется при истинности условия.

Пример программы:
```
int x = 1;
while (x < 1000) {
    cout << x;
    x *= 2;
}
```

* Второй вид — цикл do-while, который соответствует строке правила:

do statement while ( expression ) ;

Сначала записывается ключевое слово do, затем инструкция statement, после неё — ключевое слово while и условие в круглых скобках. В конце обязательно ставится точка с запятой.

Пример программы:
```
int x = 1;
do {
    cout << x;
    x++;
} while (x < 5);
```

* Третий вид — цикл for, который соответствует строке правила:

for ( init-statement conditionopt ; expressionopt ) statement

После ключевого слова for в круглых скобках записываются начальная инструкция init-statement, условие condition и выражение expression. После круглых скобок записывается инструкция statement.

Пример программы:
```
for (int i = 0; i < 5; i++) {
    cout << i;
}
```

* Четвёртый вид — range-based for, который соответствует строке правила:

for ( for-range-declaration : for-range-initializer ) statement

На естественном языке: после ключевого слова for в круглых скобках записывается переменная цикла for-range-declaration, после двоеточия указывается последовательность или диапазон for-range-initializer, по которому выполняется перебор. После круглых скобок записывается инструкция statement.
Пример программы:
```
int a[] = {10, 20, 30};
for (int x : a) {
    cout << x;
}
```
Таким образом, приведены четыре вида инструкций цикла: while, do-while, for и range-based for.
