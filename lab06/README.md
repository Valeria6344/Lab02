Ни один из четырёх вариантов не объявляет константу этапа трансляции в C++. Для этого требуется, чтобы всё выражение и используемые функции допускали вычисление на этапе компиляции.

```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

В программе объявлена переменная s, начальное значение которой равно 0. 
Внешний цикл выполняется 4 раза, а внутренний — 3 раза.
В обоих циклах используется переменная i, но это разные переменные, поскольку они объявлены в разных областях видимости. 
Внутренняя переменная i скрывает внешнюю на время выполнения внутреннего цикла.

Внутренний цикл каждый раз прибавляет к s значения 0, 1 и 2, то есть сумму 3. 
После завершения внутреннего цикла выполняется s += i, где используется внешняя переменная i.

В результате вычисляется сумма: `(3 + 0) + (3 + 1) + (3 + 2) + (3 + 3) = 18`.

Внутренняя переменная скрывает внешнюю, но после завершения внутреннего блока внешняя переменная снова становится доступной.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

Программа создаёт две строки длиной 100 000 символов и миллион раз меняет их местами с помощью временной строки c. 
При этом содержимое строк копируется, что увеличивает время выполнения.

Результат выполнения: ab

Обмен выполняется чётное количество раз, поэтому строки возвращаются к исходным значениям.

* Использование функции swap()

Функция swap() меняет значения двух строк местами. Для строк std::string она обычно обменивает внутренние ресурсы без копирования всех символов.
```
#include <iostream>
#include <string>
int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');
    for (int i = 0; i < 1000000; i++) {
        a.swap(b);
    }
    std::cout << a[0] << b[0] << std::endl;
    return 0;
}
```
Результат выполнения: ab

Функция swap() позволяет избежать многократного копирования длинных строк, благодаря этому выполнение программы значительно ускорилось. 

* Ошибка исходной программы
 
Недостаток заключается в неэффективности — на каждой итерации создаётся копия строки и выполняются два копирующих присваивания. 
Это приводит к лишним операциям с памятью и увеличивает время работы.

* Исправленная программа

Для ускорения сохраним временную переменную и присваивания, заменив копирование перемещением ресурсов с помощью std::move.
```
#include <iostream>
#include <string>
#include <utility>
int main() {
    std::string a(100000, 'a');
    std::string b(100000, 'b');
    for (int i = 0; i < 1000000; i++) {
        std::string c(std::move(a));
        a = std::move(b);
        b = std::move(c);
    }
    std::cout << a[0] << b[0] << std::endl;
    return 0;
}
```
Результат выполнения: ab

std::move позволяет перемещать ресурсы строк вместо копирования их содержимого. 
Благодаря этому сохраняется общий вид программы, но уменьшается количество затратных операций.

Исходная программа работает менее эффективно из-за копирования большого количества символов. 
Использование swap() или std::move позволяет ускорить обмен.

3. При выполнении `a += ' and goodbye'` создаётся новый строковый объект 'Hello world and goodbye', и переменная a начинает ссылаться на него. Переменная b продолжает ссылаться на исходную строку 'Hello world'.

Исходная строка используется при присваивании a. При b = a новая строка не создаётся. При добавлении текста с помощью a += ' and goodbye' создаётся новый строковый объект.
Функция id() возращщает идентификатор объекта. Его используют для сравнения объектов. В Python он обычно соответствует адресу объекта в памяти.

Присваивание b = a не копирует строку, а позволяет двум переменным ссылаться на один объект. 
Строки в Python относятся к неизменяемым объектам. Поэтому добавление текста не изменяет исходный объект, а приводит к созданию нового строкового объекта.

*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*
```
letters = "abcdefghijklmnopqrstuvwxyz"
for letter_number in range(26):
    letter = letters[letter_number]
    for number in range(100):
        variable_name = letter + str(number)
        variable_value = letter_number * 100 + number + 1

print(a0, a1, a99)
print(b0, b1, b99)
print(z0, z1, z99)
```
