### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку*
```
a,b = b,a
```
*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически
правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

В С++ оператор ',' имеет более низкий приоритет, чем оператор присваивания.Поэтому выражение разбивается на три части:
```
a;
b = b;
a;
```
Первая и последняя части просто вычисляют а. Средняя часть присваивает переменной b ее же значение.
Чтобы вычислить такое выражение можно использовать временную переменную:
```
int t = a;
a = b;
b = t;
```

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```

Запись x-->0 не является единым оператором -->. Она разбивается на три токена:
1. Идентификатор 'x'
2. Оператор постфиксного декремента '--'
3. Оператор сравнения '>'
 Литерал '0'
Таким образом, строка представляет собой пять одинаковых логических выражений, объединенных оператором логического И:
```((x--) > 0) && ((x--) > 0) && ((x--) > 0) && ((x--) > 0) && ((x--) > 0)```

* Наивысший приоритет имеет постфиксный инкремент/декремент '--'.
* Ниже приоритет у оператора сравнения '>'.
* Самый низкий приоритет у логического И '&&'.
Следовательно, сначала выполняется 'x--', результат сравнивается с нулем '> 0', и только потом результаты этих сравнений объединяются через '&&'.

По стандарту языка C++ (раздел о логических операторах), оператор логического && применяется строго слева направо. Левый операнд всегда вычисляется первым.

Побочное действие — это изменение состояния программы. В данном случае это уменьшение переменной x на единицу.
Постфиксный x-- устроен так: он возвращает в выражение текущее значение x, а само уменьшение переменной происходит чуть позже, но до того, как начнет вычисляться следующий операнд &&.

* Побочные действия, связанные с вычислением левого операнда, упорядочены до вычисления правого операнда.
Если левый операнд равен false, то вычисление правого не выполняется.
Суффиксный -- гарантирует, что побочное действие (уменьшение x) произойдет после вычисления результата самого выражения x--, но до перехода к следующей части &&.

Когда цепочка вычислений прервется на первом же ложном условии. Переменная x будет уменьшаться на 1 ровно столько раз, сколько условий успело провериться.

* Если x <= 0 (при x = 0):
Первое условие дает false. x уменьшается на 1 (становится -1). Вычисление останавливается.
Вывод программы: x = - 1.

* Если 0 < x <= 4 (при, x = 2):
(2 > 0) — true. x становится 1.
(1 > 0) — true. x становится 0.
(0 > 0) — false. x становится -1. Вычисление останавливается.
Сколько бы ни было исходное x от 1 до 4, оно уменьшится до 0, затем проверка 0 > 0 даст false и произойдет последний декремент до -1.
Вывод программы: -1.

* Если x >= 5 (например, x = 10):
Все пять условий (x > 0) будут истинными, так как x будет последовательно принимать значения 10, 9, 8, 7, 6. Побочное действие сработает 5 раз.
Вывод программы: x - 5 (для 10 выведет 5).



### Задание 8 **(3)**

*Какое число выводит следующий фрагмент программы? Посчитайте результат без использования
вычислительной техники. Отчет должен содержать процесс вычислений.*
```
int s = 0;
for (int i = 0, j = 5;i+j <= 16;(i<j ? i : j)++)
   (s += i) += j;
std::cout << s;
```

Изначальное s = 0, i = 0, j = 5.
Условие продолжния цикла: i + j <= 16.
В теле цикла выражение (s += i) += j сначала прибляет к s значение i, а затем к полученному результату значение j.
Таким образом, за одну итерацию s увеличивается на i + j.
Выражение (i < j ? i : j)++ увеличивает на 1 меньшую из двух переменных i и j. Если они равны, увеличивается j, поскольку условие i < j ложно.
После 12 итерации i = 8, j = 9. Проверка условия дает 8 + 9 <= 16, то есть 17 <= 16, ложно. Цикл завершается.
Результат программы: 126.

###  Задание 9 **(3)**
*Рассмотрите следующую программу. Предполагается, что на вход подается некоторый
индекс в массиве - число от нуля до девяти и значение, которое надо записать по этому индексу.*
```
int i = 0;
std::vector<int> x(10);
std::cin >> i >> x[i];
std::cout << x[i];
```
*Проверьте работу этой программы на различных компиляторах. Найдите два компилятора (можно 
проверить онлайн компиляторы), на которых эта программа будет давать различные ответы при одинаковом
вводе. Как это объяснить?*

В строке ```std::cin >> i >> x[i];``` сначала программа считывает целое число и записывает его в переменную i.
Затем считывается следующее число, которое записывается в элемент вектора с индексом i.

Например, если ввести: 6 44
то переменная i получит значение 6, а число 44 будет записано в элемент x[6].

```std::cout << x[i];``` выводит значение элемента вектора с индексом i. 
В данном примере программа выведет: 44

Программа считывает индекс элемента вектора, записывает в этот элемент введённое число и выводит его значение.
