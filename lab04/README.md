### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std :: cout << y << " " << z << std :: endl ;
```

Тип unsigned short обычно занимает 2 байта и может хранить значения от 0 до 65535.
Сначала: x = 40000
При вычислении x + x: 40000 + 40000 = 80000
Число 80000 не помещается в unsigned short. После преобразования к 16-битному беззнаковому типу: 80000 mod 65536 = 14464
Поэтому: y = 14464
Затем: 14464 - 40000 = -25536
При сохранении результата в unsigned short: -25536 + 65536 = 40000
Поэтому: y = 40000
Для z:
40000 * 2 = 80000
80000 mod 65536 = 14464
Поэтому: z = 14464
После деления: 14464 / 2 = 7232
Итоговый результат: 40000 7232

При арифметических операциях unsigned short сначала продвигается до int, но при записи результата обратно в unsigned short значение, не помещающееся в 16 бит, преобразуется по модулю 65536. Поэтому после переполнения исходное значение уже нельзя восстановить обычным делением.

Максимальное значение 32-битного int равно: 2 147 483 647
Поэтому происходит переполнение знакового типа.
В стандартном C++ знаковое переполнение является неопределённым поведением. На обычной 32-битной системе с дополнительным кодом получается:
3 000 000 000 - 4 294 967 296 = -1 294 967 296

2 000 000 000 + 1 000 000 000 = 3 000 000 000
Максимум 32-битного unsigned: 4 294 967 295
Поэтому переполнения нет.

3. 2500000000U + 2500000000U

2 500 000 000 + 2 500 000 000 = 5 000 000 000
Полученное значение больше 4 294 967 295, поэтому происходит переполнение unsigned.
Для беззнакового типа результат вычисляется по модулю 2^32: 5 000 000 000 - 4 294 967 296 = 705 032 704

4. 2500000000LL + 2500000000LL

Суффикс LL означает long long.
2 500 000 000 + 2 500 000 000 = 5 000 000 000
Это значение помещается в 64-битный long long, поэтому переполнения нет.

5. 20000U * 200000U

20 000 * 200 000 = 4 000 000 000
Число помещается в диапазон 32-битного unsigned:
4 000 000 000 < 4 294 967 295
Переполнения нет.

6. 200000U * 200000U

200 000 * 200 000 = 40 000 000 000

Это больше максимального значения unsigned.
Поэтому: 40 000 000 000 mod 4 294 967 296 = 1 345 294 336

###  Задание 9 **(2)**
*Напишите программу на языке С++ для умножения заданного целого числа на* $-1$. *В программе можно использовать только сложение и битовые
операции. Условия, циклы, библиотечные функции использовать нельзя.*

Для получения отрицательного числа используется дополнительный код:

-x = ~x + 1

Сначала оператор ~ инвертирует все биты числа, затем к результату прибавляется 1.

Например, для числа 5:

  5 = 00000101
 ~5 = 11111010
~5+1 = 11111011 = -5

Программа:
```
#include <iostream>
int main()
{
    int x;
    std::cin >> x;
    int y = ~x + 1;
    std::cout << y;
    return 0;
}
```

Оператор ~ является побитовой инверсией, а + 1 используется для получения дополнительного кода отрицательного числа.
